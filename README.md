# Прогнозирование времени между ДТП (2020)

**Курсовая работа по машинному обучению.**
Разработана модель для прогнозирования времени до следующего дорожно-транспортного происшествия на основе данных о ДТП в Москве за 2020 год. Проект включает в себя полный цикл Data Science: от загрузки и очистки данных до построения и интерпретации модели машинного обучения.

## 📁 Данные
В работе используются данные из трех источников (листов Excel-файла `2020.xlsx`):
*   **ДТП:** Основная информация о происшествиях (время, место, тип, погодные условия и т.д.).
*   **Участники:** Данные об участниках ДТП (стаж вождения, нарушения ПДД).
*   **ТС:** Информация о транспортных средствах (тип, год выпуска, характер повреждений).

## 🎯 Цель исследования
Прогнозировать временной интервал (в секундах) до следующего ДТП на основе текущего момента времени и сопутствующих факторов. Это задача регрессии, которая может быть использована для анализа дорожной ситуации и оценки рисков.

## 🛠️ Используемый стек
*   **Язык:** Python
*   **Библиотеки:**
    *   `pandas`, `numpy` — для обработки и анализа данных.
    *   `matplotlib`, `seaborn`, `plotly` — для визуализации данных.
    *   `scikit-learn` — для предобработки данных и разбиения выборки.
    *   `lightgbm` — для построения градиентного бустинга.
    *   `shap` — для интерпретации модели.

## 🧠 Подход к решению
1.  **Feature Engineering:**
    *   **Временные признаки:** Извлечение часа, дня недели, месяца, сезона, времени суток и циклическое кодирование времени (`sin`/`cos`), чтобы учесть его периодичность.
    *   **Географические признаки:** Группировка координат для создания "гео-ячеек" и вычисление времени с прошлого ДТП в этой ячейке.
    *   **Агрегация данных:** Создание сводных признаков на основе таблиц `участники` и `ТС` (количество участников, средний стаж, средний возраст ТС и др.).
    *   **Индикаторы пропусков:** Для важных признаков добавлены бинарные флаги, чтобы модель могла учитывать сам факт отсутствия данных.
    *   **Признаки скользящего окна:** Вычисление количества ДТП за последние 1, 6 и 24 часа.

2.  **Моделирование:**
    *   В качестве основной модели используется **LightGBM Regressor**.
    *   Из-за сильной асимметрии целевая переменная (`время до следующего ДТП`) была логарифмически преобразована.

3.  **Интерпретация:**
    *   Для выявления наиболее важных факторов, влияющих на прогноз, используется **SHAP** (SHapley Additive exPlanations).

## 📈 Ключевые результаты
Модель способна прогнозировать временные интервалы между ДТП, учитывая сложные зависимости от времени, местоположения и характеристик происшествия. Основные факторы, влияющие на прогноз, были выявлены и визуализированы с помощью SHAP-анализа.
